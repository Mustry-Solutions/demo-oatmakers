This repository is the master source for the Oatmakers demo at cloud.mustrysolutions.com
and the shared production repo of Lab 07 of the CI/CD for Ignition course.

- The application lives in `projects/oatmakers/`, gateway resources in
  `services/config/`, the module manifest in `services/modules.json`,
  module binaries in `third-party-modules/`, library JARs in `jar-files/jar/`,
  simulation migrations in `db-migration/migrate/`.
- `scripts/setup.sh` starts this code at http://localhost:8088 with the
  simulation, 90 days of history and the pinned modules. After changing
  project or config resources by hand, run `scripts/scan.sh`; project changes
  do not need a gateway restart.
- The views under `views/Pages/`, `Templates/`, `Popups/` and `Docks/`, the
  page routes, session props and the stylesheet are generated by
  `tools/demo/build_views.py`. Change the
  generator, run it, commit the result; CI checks that they match.
- Production deploys ONLY through `release.yaml`: tag first
  (`<project>@vX.Y.Z`), then pin the tag in a PR. `.github/workflows/deploy.yml`
  ships every pinned project plus the gateway-level payload of the `oatmakers`
  tag. Never deploy by hand.
- Never ship or wipe the gateway's own identity: system-properties, internal
  users and identity provider, the API token, its keys and tag values.
- The repository is public: no secrets, tokens or production passwords in
  commits.
